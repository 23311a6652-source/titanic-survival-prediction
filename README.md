# Titanic Survival Prediction

A beginner machine learning project that predicts whether a Titanic passenger survived based on passenger information.

## Objective

Build and evaluate a simple machine-learning model using the Titanic dataset.

## What I Will Learn

- Loading and exploring a dataset
- Cleaning missing data
- Creating visualizations
- Training a classification model
- Evaluating model performance

## Tools

- Python
- pandas
- NumPy
- matplotlib
- seaborn
- scikit-learn
- Jupyter Notebook
