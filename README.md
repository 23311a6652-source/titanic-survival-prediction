# Titanic Survival Prediction

A beginner machine learning project that predicts whether a Titanic passenger survived based on passenger information.

## Objective

Build and evaluate a simple machine-learning model using the Titanic dataset.

## What I Will Learn

- Loading and exploring a dataset
- Cleaning missing data
- Creating visualizations
- Training a classification model
- Evaluating model performance

## Tools

- Python
- pandas
- NumPy
- matplotlib
- seaborn
- scikit-learn
- Jupyter Notebook

## Model

I trained a Logistic Regression model to predict whether a Titanic passenger survived.

The dataset was split into:
- 80% training data
- 20% testing data

The model was evaluated using accuracy, a confusion matrix, and a classification report.
